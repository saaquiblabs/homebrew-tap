# Saaquib Labs Homebrew tap

```bash
brew install saaquiblabs/tap/<formula>
```

| Formula | What |
|---|---|
| [`lost-buttons`](https://github.com/saaquiblabs/lost-buttons) | Your mouse's side buttons, back on macOS. |
| [`curtain`](https://curtain.saaquiblabs.com) (cask) | Brightness for every screen, and turn any screen off, from the menu bar. Builds on your Mac and goes in /Applications. |
